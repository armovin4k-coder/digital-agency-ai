# Creative Ops — отчёт этапа 4

## Реализовано

- Адаптивная Kanban-доска с пятью статусными колонками.
- Drag-and-drop на `@dnd-kit/core`, pointer и keyboard sensors.
- Перетаскивание активируется только для карточек, для которых у текущей роли есть хотя бы один допустимый переход.
- Подсветка целевой колонки в зависимости от допустимости перехода.
- Все смены статуса выполняются через защищённый API; серверная машина статусов остаётся источником истины.
- Возврат на правки требует комментарий; сдача на проверку требует result-вложение.
- При сдаче из Kanban пользователь указывает ссылку на результат, которая регистрируется как вложение до перехода статуса.
- Фильтры по приоритету, GEO, офферу, исполнителю, «Мои» для креативщика и текстовый поиск.
- Карточка задачи показывает оффер, GEO, тип и количество, приоритет, дедлайн, исполнителя, число правок и количество файлов.
- Форма создания задачи с валидацией полей, ссылками на референсы и файлами.
- Добавлены shadcn-style primitives `Button`, `Input`, `Textarea`.
- Добавлены страницы-заглушки для аналитики, истории и настроек, чтобы навигация не приводила на 404 до этапов реализации соответствующих модулей.

## Загрузка файлов

Используется `upload` из `@vercel/blob/client` и `handleUpload` в серверном route handler. Токен выдаётся только после серверной авторизации и проверки контекста загрузки. Байер может запросить токен только для референсов; креативщик — для результата в задачу, назначенную ему со статусом `IN_PROGRESS`; менеджер загрузку не получает.

Серверный upload token разрешает только PNG, JPEG, WebP, GIF, MP4, WebM, QuickTime и PDF, с максимумом 25 МБ на файл. Данные Blob в MVP публичны по URL; не загружать конфиденциальные материалы. Для локального/production использования нужен Public Blob store и `BLOB_READ_WRITE_TOKEN`.

- TypeScript Transpile API: 38 TS/TSX файлов — синтаксических ошибок не найдено.
- `package.json`: корректный JSON.
- CSS: количество фигурных скобок сбалансировано.
- Проверены наличие новых App Router страниц и API-маршрутов.
- Полный `tsc --noEmit`, `next build`, браузерный DnD и подключение Neon не проверены: установка зависимостей в этой среде завершилась по тайм-ауту, БД не подключена.

## Известные ограничения текущего среза

- Подробная карточка задачи, timeline, редактирование AI-расходов и полноценная лента истории — этап 5.
- Аналитика руководителя — этап 6.
- Private Blob и аутентифицированный просмотр файлов необходимы перед использованием системы для конфиденциальных материалов.
- В интерфейсе сдача результата пока выполняется ссылкой. Загрузка результата файлом будет доступна из карточки задачи на этапе 5.
