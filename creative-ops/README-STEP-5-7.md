# Отчёт по этапам 5–7 Creative Ops

## Этап 5 — карточка задачи

- Страница `/tasks/[id]` с серверной проверкой ролевого доступа.
- ТЗ, роли участников, дедлайн и приоритет.
- Файлы-референсы и результаты по раундам.
- Добавление результата ссылкой или файлом с проверкой доступа.
- Таймлайн: создана, взята, последняя сдача, завершена; длительности этапов.
- AI-кредиты по сервису, участнику и раунду.
- Комментарии и неизменяемая лента ActivityLog.
- Действия buyer/creative/manager по матрице доступа.
- Переназначение активной задачи руководителем.

## Этап 6 — аналитика и история

- `/analytics` — только MANAGER.
- Фильтр периода.
- KPI: задачи, в работе, просрочки, среднее время производства, AI-кредиты.
- Графики статусов, текущей загрузки, среднего времени, расходов AI по сервисам/исполнителям и просрочек.
- Таблица эффективности креативщиков.
- Среднее время от takenAt до completedAt и полный цикл createdAt → completedAt.
- `/history` — лента ActivityLog с фильтрами по действию, периоду и поиском; API ограничивает выдачу матрицей доступа.

## Этап 7 — полировка и документация

- Светлая/тёмная тема через next-themes.
- Адаптивные макеты detail/analytics/history/settings.
- Empty states, skeleton/загрузочные состояния, toasts, keyboard focus.
- Обновлённый README: запуск, БД, роли, workflow, API, деплой, AI workflow и ограничения.

## Проверки

Первоначальная генерационная среда не позволила установить npm-зависимости из-за DNS-ошибки. Этот статус устарел: последующая локальная проверка прошла успешно. Актуальные результаты и ограничения приведены в разделе «Фактический статус проверок» файла [README.md](./README.md).

## Дополнительная финальная корректировка

- Добавление нового референса через карточку задачи теперь обновляет и `Task.references`, и `Attachment`, не создавая дубликат ссылки в массиве задачи.
- Среднее время производства и полный цикл в аналитике теперь используют `completedAt` выбранного периода; количество созданных задач и распределение статусов используют `createdAt`.
- Дедлайн при создании и редактировании проверяется Zod на сервере и должен быть в будущем.
- Максимальный размер метаданных вложения ограничен 25 МБ на API-уровне.


## Финальный аудит проекта

- Актуальные версии зависимостей проверены; `npm audit` завершился без уязвимостей.
- TypeScript, ESLint, Prisma validation, unit- и PostgreSQL integration-тесты и production build прошли.
- Локальный вход и доступ к доске проверены в браузере; анонимный API-запрос возвращает `401`.
- Загрузка файлов в private Vercel Blob не проверена без локального `BLOB_READ_WRITE_TOKEN`.
- Для полного перечня результатов и ограничений см. [README.md](./README.md) и [TECHNICAL-AUDIT.md](./TECHNICAL-AUDIT.md).
