2. Какие данные и для чего обрабатываются

Через форму могут быть получены имя, телефон, адрес электронной почты или имя пользователя в Telegram, а также описание задачи. Эти сведения нужны, чтобы принять обращение, связаться с заявителем и обсудить запрошенные услуги.

Не отправляйте через форму пароли, платёжные реквизиты, специальные категории персональных данных и сведения, которые не нужны для ответа на запрос.

3. Основание, действия и передача данных

Отправка формы возможна только после отдельного активного согласия заявителя. Обработка включает получение, просмотр, систематизацию, использование для ответа, хранение в используемом канале обращений и удаление.

Для доставки заявки ответственному менеджеру используется Telegram. Отправляя форму, заявитель соглашается на передачу указанных в ней данных через этот сервис; сам сервис может обрабатывать сведения в соответствии со своими условиями и документами. Заявка не используется для рекламных рассылок.

Для отображения шрифтов и значков браузер загружает ресурсы Google Fonts и cdnjs. При таких запросах соответствующие поставщики могут получать технические сведения соединения, например IP-адрес; содержимое заявки им не передаётся.

4. Срок хранения и отзыв согласия

Оператор хранит заявку не более 12 месяцев после последнего контакта по ней и удаляет её из доступного ему рабочего чата, если более длительное хранение не требуется по закону или для защиты законных требований. Telegram может обрабатывать и хранить технические данные по собственным условиям; оператор не устанавливает сроки хранения данных на стороне Telegram. Согласие можно отозвать, обратившись по телефону, указанному в разделе 1. Отзыв не отменяет законность обработки, выполненной до его получения.

Сайт не устанавливает рекламные или аналитические cookie. При закрытии cookie-уведомления браузер получает технический cookie da_cookie_notice сроком на один год, чтобы не показывать это уведомление повторно.

Чтобы уточнить сведения, потребовать их исправления или удаления либо отозвать согласие, свяжитесь с оператором по телефону, указанному в разделе 1.
